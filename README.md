# Anna — Personal portfolio

A responsive, static portfolio built with HTML and CSS. Open `index.html` in a browser to view it. No installation or build step is needed.

## Files

- `index.html` — page content
- `styles.css` — layout and responsive styles
- `Basquiat-devil-1982.jpg` — supplied favorite painting image

All assets are local and referenced with relative paths. The typeface uses the visitor's system fonts; there are no external services or JavaScript dependencies.

## GitHub Pages

Push these files to your GitHub repository. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select your branch and **/(root)**, then save. GitHub will provide the published website address.

The painting is presented as Anna's favorite artwork, not as her own design work. Its supplied image is 425 × 202 pixels, so some softness is expected when displayed larger.
